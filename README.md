# Process Feedback Assignment Submission

This plugin (`assignsubmission_processfeedback`) works together with
[`local_processfeedback`](https://github.com/processfeedback/moodle-local_processfeedback).
The local plugin records writing process data in the student's browser and uploads
it with their assignment submission. This plugin receives, stores, and displays that data.

Both plugins are required. See the
[local plugin's README](https://github.com/processfeedback/moodle-local_processfeedback#readme)
for installation and setup instructions.
